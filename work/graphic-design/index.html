Process breakdowns

How the work actually gets made

Building Guidelines People Actually Use

The test of a brand guideline is simple: six months later, when the person using it was not in the room, does the output still look right? That only happens if the document teaches reasoning, not just appearance.

  1. 01Start with the decisions people actually make — not the logo variations.
  2. 02Show the wrong answers alongside the right ones, so the rule is obvious.
  3. 03Give rules with a reason attached, so edge cases can be reasoned about.
  4. 04Ship templates that pre-apply the rules, so the default is correct.
