How the work actually gets made

The Edit Workflow

Edit order decides cost. Working rough and locking structure before polish is what keeps a revision round from becoming a re-shoot.

  1. 01Lock the structure against the approved script before any polish.
  2. 02Cut for sound first — pacing lives in the audio far more than people expect.
  3. 03Add captions and graphics once the pacing is final.
  4. 04Grade last, then export every ratio from the same master.
